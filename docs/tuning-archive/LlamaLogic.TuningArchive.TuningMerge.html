Remarks

Elements are matched by name (the element of a variant by the variant's option), and list items are aligned, so that a changed item is not mistaken for one removed and another added: items are the same item when their XML is the same, or, for items with members, when at least half of their values are.

Where only one side changed an element, the merge takes that side's version. Where both changed it differently, or one removed an item the other changed, that is a conflict, resolved as the caller says (by default, the game's version). Items both sides added at the same place are all kept, the game's first, and an item both added is kept once (where the mod put it, if they put it in different places). Attributes merge the same way, so a change the mod made to the root element's attributes is kept.
