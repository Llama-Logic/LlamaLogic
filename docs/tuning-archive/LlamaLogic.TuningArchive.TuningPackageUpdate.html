Remarks

For each override, the base (the game version the mod was most likely made from) is the archive snapshot, up to the target, whose version of the tuning has the fewest differences from the override. When versions with different content are as close, the base is the oldest of them, because they tie when the mod changed what the game later changed, and the older base shows that as a conflict rather than taking the mod's version as up to date. If the game changed the tuning between the base and the target, the mod's changes are merged onto the target's version (see TuningMerge).

The package is never changed: WriteAsync(string, IReadOnlyDictionary<ResourceKey, string?>, TuningPackageSimDataChanges, TuningCommenter?, CancellationToken) writes a new one, copying every resource it is not told to change.
