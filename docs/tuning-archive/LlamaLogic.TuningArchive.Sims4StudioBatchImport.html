Remarks

Batch import reads a resource's key from the start of its file name, up to the first period: the type, group and instance in hexadecimal, separated by exclamation points. Sims 4 Studio's batch export follows the key with the resource's name and type, for people, as in 6017E896!00000000!0000000000012345.buff_Example.BuffTuning.xml, and so do these names. Characters Windows doesn't allow in file names become underscores, as they do in Sims 4 Studio's export.
