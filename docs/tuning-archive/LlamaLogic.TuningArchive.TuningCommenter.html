Remarks

The comments are the ones ExportAsync(TuningArchiveSnapshot, string, TuningArchiveExportOptions?, IProgress<TuningArchiveProgress>?, CancellationToken) writes: found with the snapshot's tuning descriptions when it has them and they describe the tuning, and otherwise as XML Extractor finds them, as any number that is a string's key or a tuning's instance. References to tuning of packs that were not installed when the snapshot was captured are commented with the names the packs' patches give it (see GetUninstalledTunings(TuningArchiveSnapshot)). The game ignores comments, so tuning with them loads as it would without them.

Remarks

Comments already in the text are kept. The result is indented with two spaces, with the line ends the text has, and starts with an XML declaration if the text does.
