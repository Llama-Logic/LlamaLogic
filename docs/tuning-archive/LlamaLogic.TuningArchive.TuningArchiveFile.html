Remarks

Each TuningArchiveSnapshot records the tuning, SimData and strings of a version of the game, as captured from an installation or imported from extracted files. Content is stored once however many snapshots contain it, and each resource's history is kept as ranges of snapshots, so a snapshot adds only what changed.

An archive's members are safe to use from multiple threads. Operations that change the archive are serialized.

An application that only reads an archive another application maintains should open it with OpenReadOnly(string), which never changes the file, rather than Open(string), which upgrades the file to this library's version.

Remarks

Media are the images, sounds and videos to which the captured tuning and SimData refer (with the audio the sounds use), taken from the client packages of the packs with the same rules as tuning; which kinds are captured is up to the options. Strings are merged from every string table of every pack the way the game merges them: a string in a package of higher priority replaces the same string in a package of lower priority (packages of the same priority in pack order, the base game first), so a pack's Delta strings add to and correct its installed strings rather than replacing them. Within a pack, tuning, SimData and animation state machines are taken from the pack's Delta packages before its installed packages, because the Delta folder patches the installed one: its resources replace theirs and its delete records retire theirs, whatever priorities the two folders' configurations assign. The game does not load the patches of packs that are not installed, so their tuning is not captured; only the names of the tunings they patch are recorded (see GetUninstalledTunings(TuningArchiveSnapshot)), so that what refers to them can still be explained.

Remarks

Each resource is written to a folder for its pack (such as EP01) and, in it, a folder for its tuning type (such as buff) or AsmJazz, as indented UTF-8 XML with a byte order mark and CRLF line endings. SimData is written beside the tuning with its instance, so that both can be chosen together for Sims 4 Studio's batch import, or to a SimData folder in its pack's folder if there is no such tuning. The group in file names is the pack's identifier, as XML Extractor writes it: taken from the snapshot's game scripts when it has them, otherwise from the pack stamp of the pack's SimData, otherwise from XML Extractor's own table of packs.

A tuning that more than one pack contains is written once, to the folder of the pack the snapshot attributes it to; XML Extractor writes it to the folder of each pack. The archive does not keep the order of the attributes the game ships, so elements' attributes are in canonical order (see TuningXml), with the n and t attributes ordered as AttributeOrder specifies. References to tuning of packs that were not installed are commented with the names the packs' patches give it, as XML Extractor comments them (see GetUninstalledTunings(TuningArchiveSnapshot)), and those names are in the reference files, but the tuning itself is not exported.

GetVoiceVersionInstance(ulong, string)

Gets the instance of the version for the voice with the specified voiceCode (see VoiceCodes) of the audio configuration that tuning names with the specified instance

public static ulong GetVoiceVersionInstance(ulong instance, string voiceCode)

Parameters

instance ulong
voiceCode string

Returns

ulong

Remarks

Tuning names some sounds sims sing or speak (vocal_clip in recipes, for example) by the FNV-1 64 hash of a file name that has no audio configuration of its own, such as vo_karaoke_solojazz2_tune_67sec. The game has a configuration for each voice instead, hashed from the file name followed by an underscore and the voice's code (vo_karaoke_solojazz2_tune_67sec_fa). FNV-1 has no finalization, so the version's instance is found by continuing the hash from the instance tuning names, without the file name.

GetVoiceVersionSource(TuningArchiveSnapshot, TuningArchiveEntry)

Gets the instance by which tuning names the audio configuration of which the specified entry is a voice's version, with that voice's code, or null if it is not a voice's version (see GetVoiceVersionInstance(ulong, string))

public (ulong instance, string voiceCode)? GetVoiceVersionSource(TuningArchiveSnapshot snapshot, TuningArchiveEntry entry)

Parameters

snapshot TuningArchiveSnapshot
entry TuningArchiveEntry

Returns

(ulong instance, string voiceCode)?

Remarks

A configuration is taken to be a voice's version when tuning in the specified snapshot refers to the configuration it would be a version of (only tunings whose references have been indexed are found; see IndexReferencesAsync(IProgress<TuningArchiveProgress>?, CancellationToken)), or another voice's version of that configuration is in the snapshot. Codes that share their first letter differ only in the last character hashed, so working back with the wrong one of them leads to a configuration with versions of its own in the snapshot (this one, and the version for another voice of the same group); of the configurations it could be a version of, the one tuning refers to is preferred, then the one with the most versions in the snapshot.

Parameters

Task<TuningArchiveCaptureResult>

Remarks

Every .xml file under the folder whose root is an instance (I) or module (M) tuning element is imported as tuning, every one whose root is SimData as SimData, and every other one whose file name has a resource key of type AnimationStateMachine (as Scumbumbo's XML Extractor names the files in its AsmJazz folders) as an animation state machine. A tuning's type is derived from its i attribute the way the game derives it, falling back to a resource key in its file name, and its group is always 0 (the game identifies tuning by type and instance); comments are discarded. A file is attributed to the pack named by a folder in its path (such as EP01), or to DefaultPack.

A file named Reference - All Strings.txt in the folder, as Scumbumbo's XML Extractor writes it, is imported as the snapshot's strings.

Exceptions

NotSupportedException

The archive was opened for reading only

Remarks

The archive can be read while another application has it open with Open(string), and sees what that application writes as it is written. Members that would change the archive throw NotSupportedException.

If the archive's reference index was built by a different version of this library, it is left as it is and treated as empty: members that use it find no references, and GetReferenceIndexStatus() reports no tunings indexed.
