Remarks

The canonical form is UTF-8 without a byte order mark, an XML declaration, two-space indentation and line feeds, with comments removed. The root element's attributes are in ordinal order (c, i, m, n, s), and every other element's are n, then t, then the rest in ordinal order. Documents with the same content therefore have the same canonical text however they were obtained (from the game's combined tuning or from files extracted by another tool).
