Specifies how ExportAsync(TuningArchiveSnapshot, string, TuningArchiveExportOptions?, IProgress<TuningArchiveProgress>?, CancellationToken) names the files it writes, following the conventions of Scumbumbo's XML Extractor

public enum TuningArchiveExportNaming

Fields

Name = 2

The name alone (such as object_drink_Cider.xml)

Native = 3

The game's own naming, without an extension (such as 0x00000000!0x00000000000029c3.0x2451c101)

The naming Sims 4 Studio uses (such as b61de6b4!00000001!000000000001c8c5.object_drink_Cider.object.xml)

TypeGroupInstance = 0

The type, group and instance, for importing into s4pe (such as S4_E882D22F_00000000_000000000001A2BC.xml)

TypeGroupInstanceName = 1

The type, group and instance followed by the name, which s4pe turns into a _KEY name on import (such as S4_B61DE6B4_00000001_000000000001C8C5_object_drink_Cider.xml)
