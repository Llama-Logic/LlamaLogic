Remarks

The game's reader and writer keep two sets of layers, LayerSet0 and LayerSet1; what distinguishes them has not been established. The headers of the layers (key and use count) come first, set by set, then MaskSizeX and MaskSizeZ, then the masks, in the same order.

Versions 2 through 4 are supported, and the game writes version 4; the lots examined hold versions 2 and 4. Version 2 has only LayerSet1, followed by Unknown1, and its layers have no HasMask. Version 3 stores LayerSet1 before LayerSet0; version 4 stores LayerSet0 first.

The game writes no keys of this section into the ResourceManifestSection, which it saves earlier.

Remarks

When its caller passes a flag of unknown meaning, the game's reader replaces the key of this set's first layer with default key 0x1E of the lot's style. It holds 0 or 1 layers in the lots examined. Sculpting the terrain with the raise tool in game added a layer to this set (in-game test).
