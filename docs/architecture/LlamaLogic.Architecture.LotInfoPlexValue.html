Remarks

The game hands the map to its plex manager after loading. In-game tests show that the value grows with each paid build change (by 960 for a room, 64 for a floor fill, 64 for a ceiling, 16 for four ground tiles, 4 for one terrain floor tile, 75 for three fence segments) and is unchanged by a rotation or a quarter-tile repaint; that it is the architecture's value is a hypothesis.
