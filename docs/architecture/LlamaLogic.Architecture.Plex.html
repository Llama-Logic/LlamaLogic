Remarks

The layout follows the game's reader and writer.

Layout, with gates on the section's version: Id (ushort), the offset within the section at which the plex ends (uint, from version 2 on), IsVisible (uint), a uint block count, the Blocks, Unknown1 and Unknown2 (after 4), the name (version 6: a uint byte count and ASCII text), then after 5 TileCount, Unknown3, Unknown4 and Unknown5. The game writes the end offset as a placeholder and patches it, so that its reader can skip the plex; the offset is not a property, it is checked on reading and computed on writing.

Name

Property Value

string

Remarks

The game reads it and discards it. Observed values are "Shared Unit" and "Unit 1". It is stored as a byte count and one byte per character, so it must be ASCII: reading a name with other bytes fails, and so does encoding a name with other characters.
