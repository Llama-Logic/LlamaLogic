WaterLevel

Gets/sets the pond's water level, in steps of 0.25 m

public int WaterLevel { get; set; }

Property Value

int

Remarks

It equals GetWaterLevel(int, int, FloorQuarter) on every quarter of the pond, which the game multiplies by 0.25. Creating a pond in game set it to −1, and raising the pond's water level one step changed it from −3 to −2 together with the water level of every quarter of the pond in the TerrainHeightsSection, while the pond spread to more cells (in-game tests). It is −1, −2, −3 or 0 in the lots examined.
