Remarks

The game's floor feature manager reads and writes the section and exposes it to Python as get_floor_feature, set_floor_feature, has_floor_feature, list_floor_features and scan_floor_features. Each layer is stored as its type, the byte length of its payload and the payload; the game skips the payload of a layer type above 2, which this library does not support: a section holding one is kept undecoded.

Versions 0 and 1 are supported, as the game's reader accepts, and the game writes version 1, the only one in the lots examined. The section needs the lot's dimensions.
