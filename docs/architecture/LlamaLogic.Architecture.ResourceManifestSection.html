Remarks

The game builds the manifest while saving: it records every key it writes in the sections that precede the manifest in its save order, skipping repeats, so the manifest starts with the lot's style key and the null key. GetManifestKeys() does the same with the current sections. The game writes the manifest, but no code in the game's simulation library reads it back (other parts of the game were not examined). The section has no version.
