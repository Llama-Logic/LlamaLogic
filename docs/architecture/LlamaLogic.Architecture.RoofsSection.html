Remarks

The header holds LegacyKey (before version 8), ReservedKey, Unknown1, Unknown2, Unknown3 and the roof count (a 32-bit value); the roofs follow. The layout of each roof depends on the version, as Roof describes.

Versions 5 through 13 are supported, and the game writes version 13.

In-game tests show that a roof's shape is decided by its RoofKey alone, with the per-side bytes following the shape; Roof lists the observations.
