Remarks

The file is a 32-bit version and the length of its content, followed by the content compressed with Snappy (the raw block format). The content is a header, the LotObjects as a protobuf message, ObjectDefinitionMappings, Images and finally the Architecture as a record bundle. Blueprints without the header (HasHeader is false) hold only the objects and the architecture; Sims 4 Studio reads them, but none has been observed.

Snappy compressors differ in their output, so Encode() reuses the compressed bytes it decoded when the content it would write is unchanged, and otherwise compresses the content anew. Decoding and encoding a blueprint the game wrote therefore reproduces it byte for byte.
