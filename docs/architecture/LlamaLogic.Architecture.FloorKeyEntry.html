ReferenceCount

Gets/sets the number of references to the entry, counted in tile quarters

public uint ReferenceCount { get; set; }

Property Value

uint

Remarks

The game decrements it as quarters stop using the id and frees the entry at 0; it is never 0 in the lots examined. It equals the number of quarters holding Id across the seven FloorIdGridSection grids in 18,597 of the 18,773 entries examined in lots whose grids can be read, and is larger in the rest, which suggests other sections also hold references. This library does not recompute it.
