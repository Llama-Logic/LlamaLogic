Remarks

The grid has SizeX × SizeZ tiles per layer and four ids per tile, one per FloorQuarter. Each id is a Id of the lot's FloorKeysSection, whose key is a CTProductFloorPattern (0xB4F762C9); 0 means no floor.

The types Floors, Ceilings, PoolSurfaces, SecondaryFloors and CeilingPaints have one layer per level of the lot (HasLevels), indexed by level − LowestLevel, so ground level is index −LowestLevel. TerrainFloors and PondBottoms have a single layer, for ground level. When the lot's Version is 8 or less, PoolSurfaces also has a single layer, for ground level.

Roles proven by the game's code and in-game tests: Floors is the floor pattern of each level, TerrainFloors the floor pattern painted on bare terrain, PondBottoms the pond bottom pattern and CeilingPaints the ceiling paint. In-game tests show that building a room fills Ceilings at the level above the room over exactly the room's tiles (and painting the ceiling changes only CeilingPaints), and that building a pool fills PoolSurfaces over exactly the pool's tiles at the level above the pool's block; the game's code assigns both grids to the room on the level below their layer. In-game tests show that building a room or a platform fills SecondaryFloors over its tiles with the lot's default floor key, and that painting a floor or a platform's top changes only Floors; the role of SecondaryFloors, which covers the same quarters as Floors, is still unknown.

The layers are stored one after another, each as SizeX rows of SizeZ tiles of four little-endian 16-bit ids; the section has no version.
