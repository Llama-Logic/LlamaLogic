Specifies the type of a WallBlock

[SuppressMessage("Design", "CA1028: Enum Storage should be Int32", Justification = "The game stores the value as a byte.")]
public enum WallBlockType : byte

Fields

Fence = 1

A fence line

Placing a fence creates a block of this type (in-game test). The game allows it only at level 0 and gives it no elevation.

Fountain = 2

A fountain

The game emits CantPlaceFountainUnderAnything for it, gives it a height of 0.375 and allows it only at level -1.

Pool = 3

A pool

The game emits CantPlacePoolUnderOtherPool for it; placing a pool creates a block of this type (in-game test).

Standard = 0

A block that is not a fence, fountain or pool

In the lots examined these are rooms and free-standing wall lines, and a platform is a block of this type too: drawing one creates a block whose segments are all Open until walls are added, raised by FloorHeightOffset just as a room whose floor is raised (in-game tests); that the type covers nothing else is a hypothesis.

Remarks

The game checks each block type against the WallBlockSegmentKind of the block's segments with a table: a Fence block allows only Open, a Fountain or Pool block only Wall and ModularPieceWithWall (otherwise BlockTypeIncompatibleWithProduct).
