Remarks

The grid has SizeX × SizeZ tiles per layer and one rotation of 0 through 3 per FloorQuarter. A rotation is the number of 90° clockwise turns of the pattern, as seen in game: rotating one floor tile by 90° changed all four of its quarters from 0 to 1, and so did turning a terrain floor tile 90° clockwise (in-game tests). Each grid is paired with a floor id grid: FloorRotations with Floors, CeilingRotations with Ceilings, SecondaryFloorRotations with SecondaryFloors, CeilingPaintRotations with CeilingPaints and TerrainFloorRotations with TerrainFloors; FloorIdGridSection describes the roles of the id grids and the in-game tests and code that show them.

All types but TerrainFloorRotations have one layer per level of the lot (HasLevels), indexed by level − LowestLevel; TerrainFloorRotations has a single layer, for ground level.

The layers are stored one after another, each as SizeX rows of SizeZ bytes; each byte holds the four rotations of a tile, two bits each, the NegativeZ quarter in the lowest bits, as the game's getter and setter read and write them. The section has no version.
