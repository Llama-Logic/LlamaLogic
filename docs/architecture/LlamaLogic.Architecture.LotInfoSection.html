Remarks

The layout is Unknown1 (from version 13 on), the lowest and highest levels (signed bytes), one height per level from the lowest to the highest, LevelElevationOffset (from version 6 on), NegativeLevelElevationOffset (from version 16 on), Unknown2 (from version 17 on), Unknown3 (from version 18 on) and StyleKey (from version 7 on). From version 11 on, BlueprintInstance, the ids of the two users, Uuid, the names of the two users and, from version 19 on, the rest of the two user records follow. Versions 12 through 14 end with one plex map entry (value and has-value flag) and versions 15 and later with a 32-bit entry count and the entries.

The highest level is not kept: it is LowestLevel plus the number of LevelHeights minus 1, which the game's reader relies on to read the heights. The number of heights equals LevelCount.

Versions 5 through 20 are supported, and the game writes version 20. The game reads some other sections only for some versions of this one (for example PendingPlacementSection from version 9 on).
