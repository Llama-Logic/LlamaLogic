Remarks

The layout follows the game's reader and writer. Versions 0 through 2 are supported, and the game writes version 2; the lots examined hold only version 2.

Layout: Version, StampCounter (after 1), a ushort block count, then per block its Id (ushort, the key of the game's block map, which the game writes from the block) and the WallBlock.

Remarks

The game keeps it at offset 0x58 of its block manager. Adding a foundation raised it by 1 and set the stamps of the block's segments to the new value (in-game test). It is at least the highest Id in every lot examined; of the 653 lots examined without blocks, 450 hold 0 and the rest 1 through 143,271. Whether the game also allocates block ids from it is a hypothesis. Stored from version 2 on.
