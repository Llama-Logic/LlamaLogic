Collection<FloorFeatureLevel>

Remarks

A level of a layer of type 0 or 1 has one value per tile (SizeX and SizeZ are the lot's); a level of a layer of type 2 has a single value (both are 1).

Type

Gets/sets the type of the layer, 0 through 2

public byte Type { get; set; }

Property Value

byte

Remarks

The game rejects other types as an "Invalid layer type"; the names of the three types are not in the game's code. In the lots examined the values of type 0 are 0 or 255, those of type 1 are 0, 127, 128 or 255, and those of type 2 are 0; layers of type 2 have no levels in all but 6 records.

Exceptions

ArgumentOutOfRangeException

The type is not 0 through 2
