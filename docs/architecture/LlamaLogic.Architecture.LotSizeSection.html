Remarks

The grids of the other sections are SizeX tiles along the lot's local X axis by SizeZ tiles along its local Z axis, with one layer per level. LevelCount is the number of levels from the lowest to the highest of LotInfoSection, inclusive.

Versions 2 through 13 are supported, and the game writes version 13. Version 2 holds no dimensions (HasDimensions is false); the game discards the floor data of such a lot.
