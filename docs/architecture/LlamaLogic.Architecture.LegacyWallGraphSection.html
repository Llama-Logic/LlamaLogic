Remarks

No code in the game's simulation library reads or writes this section (other parts of the game were not examined), so the layout comes from the lots examined and every meaning is a hypothesis. The lots examined hold 21 of these sections, all in world files; 17 are empty. The two tables have the shape of the game's ProductTable, and in each of the four non-empty sections examined every id is referenced and every ReferenceCount equals the number of references in the section.

Version 1 is the only one supported, and the only one in the lots examined.

Layout: the version (uint), the Products table, the WallPatterns table, then three lists, each an int count and its entries: Edges, ProductEdges1 and ProductEdges2.
