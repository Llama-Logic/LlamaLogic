Remarks

The game reads and writes the section right after the VertexGraphsSection, whose Version decides the layout; so the section can only be read and written together with that section. The section has no version of its own; the game writes it for a VertexGraphsSection of version 9.

Layout: a uint count, the WallPatternEdges and the WallPatterns table; if the vertex graphs version is above 1, the Products table, a uint count and the ProductEdges; if it is 6, a uint count and the LegacyEntries; if it is above 8, the AdditionalProducts table, a uint count and the AdditionalProductEdges.

Encoding throws an InvalidOperationException when a table or list that the layout of the vertex graphs version lacks is not empty.

Other tools detect the optional parts by the length that remains; in every lot examined that gives the same split as the version gates.
