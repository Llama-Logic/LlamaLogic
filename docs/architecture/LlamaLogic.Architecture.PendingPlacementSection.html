Remarks

When State is 1, the game centers a footprint of Width by Depth tiles, turned by Rotation, on the lot and builds a placement operation with BlueprintInstance; that this places a pending lot template or blueprint is a hypothesis. Every lot examined holds the defaults (state 0).

The layout is Width, Depth, Rotation (from version 3 on), State (a Boolean in version 1), then from version 2 on Unknown1, Unknown2, Unknown3 (from version 4 on) and Unknown4 (from version 5 on). The game reads this section only when Version is 9 or later.

Versions 1 through 5 are supported, and the game writes version 5.
