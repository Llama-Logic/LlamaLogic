Remarks

The game names the resource after the lot template it belongs to; see GetKey(uint). Its WorldLotArchitecture counterpart holds the lot template's architecture.

Maxis writes the text with fields in field-number order, two-space indentation, CRLF line endings and floats in .NET Framework's round-trip format; Encode() writes the same, so it reproduces every resource Maxis wrote byte for byte. Decode(ReadOnlyMemory<byte>) also reads text written otherwise (community tools add commas, reorder fields or write hexadecimal integers), and Encode() returns the decoded bytes unchanged as long as LotObjects is unchanged.
