Remarks

The products are ids into the block's Products table (0 for none); every nonzero id in the lots examined is an id of that table. The game reads them as nine slots; which slots a block version stores is described with Version, and the game fills the slots an older version does not store from the block's LegacyKeys. The slot names follow the catalog types the slots refer to in every lot examined (names from the game's CTProduct table).

Layout: the loop stores X and Z of all its segments first, then, per segment, Kind, Unknown1 (versions before 23), the stored slots in slot order, then FenceStamp and CeilingRailStamp (versions after 25).

Remarks

The game returns it with slot 3. Adding a foundation set it, together with FenceStamp, to the value StampCounter was raised to (in-game test); what the game uses it for is unknown. It equals FenceStamp in 66% of the segments of the WallBlocksSection blocks examined and in 81% of those of the PlexesSection blocks. Stored from version 26 on; older versions store one value for the whole block, LegacyStamp.
