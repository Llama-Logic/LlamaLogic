Remarks

Each graph holds vertices, under the tag "TREV" ("VERT" reversed), and edges, under the tag "TCES". What the graphs describe is not established; Sims 4 Studio calls this section WallCutout.

In in-game tests the first graph changed whenever walls, roofs, stairs or platforms were added or reshaped (including when a roof was replaced with another shape) and never for paint, trim, terrain or lot type changes; this is an observation only.

The layout follows the game's writer; on loading, the game reads only the section's version, which decides the layout of the WallEdgesSection, and does not read the graphs. Versions 5 through 9 are supported, and the game writes version 9; the lots examined hold versions 5 through 9.

Layout: Version, then the Graphs: three before version 8 and four from version 8 on, the numbers of graph objects the game's reader resets for those versions.
