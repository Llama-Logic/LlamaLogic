Remarks

architecture_data is a repeated field parallel to the message's objects field, and active_data_index selects the entry in use. Most zones have one entry, some have none, and a few have several.

These methods read and replace only that field's entries in the message's bytes and copy everything else verbatim, so they never re-serialize the rest of the message.
