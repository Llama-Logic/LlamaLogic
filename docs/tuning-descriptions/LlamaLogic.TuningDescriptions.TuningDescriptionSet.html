Remarks

A set is indexed by the paths of its documents when it is opened: instances are */Descriptions/{class}.tdesc, modules are Tuning/{module with . replaced by -}.tdesc, and fragments are TdescFrag/{class}.tdescfrag. A document is read the first time it is requested, and it may be read again once nothing refers to it any longer, so requesting a document twice does not necessarily return the same object.

A set's members are safe to use from multiple threads.
