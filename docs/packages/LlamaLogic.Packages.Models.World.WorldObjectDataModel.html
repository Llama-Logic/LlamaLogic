Remarks

A world file is a package (see DataBasePackedFile); this models one of the resources in it, not the file. Versions 7 through 10 are supported: 10 is the version of every world file the game currently ships, and 7 that of older ones. Version 8 added each object's Snow flag, version 9 each lot's StairLocators and version 10 each object's Flags.
