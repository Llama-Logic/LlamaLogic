Remarks

The game stores lot architecture in this container, as the content of a WorldLotArchitecture resource in world files, of the architecture data of a lot in a save game, and of the architecture of a tray blueprint. Each lot architecture section is one record, keyed by the section's type, group zero and a fixed instance. Encode() lays the bundle out the way Maxis does: records grouped by type and group in ascending order, keeping their order within a group, so decoding and encoding a bundle Maxis wrote reproduces it byte for byte.
