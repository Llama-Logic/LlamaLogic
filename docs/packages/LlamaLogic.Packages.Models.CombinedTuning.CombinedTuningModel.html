Remarks

Maxis ships the game's tuning merged into resources of this type, encoded either as a binary packed XML document (a DATA file) or as XML text. Decode(ReadOnlyMemory<byte>) accepts both and presents the merged document as Document. Encode() always produces XML text, written the way Maxis writes it. GetTunings() produces the individual tuning documents the merged document contains.

Remarks

The documents are produced as the sequence is enumerated, and are independent of Document and of each other. Modifying Document while enumerating has undefined results.
