Remarks

A world file is a package (see DataBasePackedFile); this models one of the resources in it, not the file. The resource is a tree of tagged chunks (OMGS, holding OMGR object managers, holding ID, LOT and OBJ chunks). Decode(ReadOnlyMemory<byte>) supports the chunks the game's world files contain and rejects the others the game can also read (MODL, DEFG, LEVL, SCRP, TRES, REFS, SIZY), whose layouts are not established. Encode() writes the chunks in the order the game's world files do, so decoding and encoding one of them reproduces it byte for byte. Older world files lack the SNOW and OPRP chunks of objects; the corresponding properties are then null and are not written. The game names the resource after its world file; see GetKey(string).
