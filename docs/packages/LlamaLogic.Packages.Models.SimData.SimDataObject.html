Remarks

Each value's .NET type is determined by its column's SimDataType: BOOL is bool; CHAR8 and UINT8 are byte; INT8 is sbyte; INT16 is short; UINT16 is ushort; INT32 is int; UINT32 and LOCKEY are uint; INT64 is long; UINT64 and TABLESETREFERENCE are ulong; FLOAT is float; FLOAT2, FLOAT3 and FLOAT4 are Vector2, Vector3 and Vector4; RESOURCEKEY is ResourceKey; STRING8 and HASHEDSTRING8 are string (or null; the hash of a HASHEDSTRING8 is computed when encoding); OBJECT is SimDataObject, VECTOR is SimDataVector, and VARIANT is SimDataVariant (each or null).
