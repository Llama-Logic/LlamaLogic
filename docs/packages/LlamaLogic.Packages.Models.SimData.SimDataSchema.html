Remarks

The order of Columns is the order in which the columns' values are laid out in each row. For schemas the game reads with a fixed layout (e.g. Client_ and Renderer. schemas), this order must match the game's, which is why Decode(ReadOnlyMemory<byte>) preserves it. The game derives a schema's hash from its name and layout (see ComputedHash), so changing the columns or their order changes the hash the game expects.

Remarks

The game computes this as the sum of the Fnv32 hash of the lowercased name, the row size shifted left 16 bits, the number of columns, and, for each column, the Fnv32 hash of its lowercased name XOR its type shifted left 16 bits XOR its offset in the row shifted left 8 bits. Column flags do not contribute.
