Remarks

A SimData resource is a set of named Instances, each an object described by a SimDataSchema whose values may refer to further objects, strings, vectors and variants. Decode(ReadOnlyMemory<byte>) reads any well-formed layout, including those written by community tools, and reads a reference whose offset is zero (which could only refer to itself, and which some community tools write) as null. It rejects a resource in which a row is referred to more than once, which Maxis never writes and which the model, being a tree, cannot represent. Encode() always lays the resource out the way Maxis does, so decoding and encoding a resource Maxis wrote reproduces it byte for byte.

Remarks

Fields are matched to columns by exact name, and every column of an object must have exactly one field. A string field written as an empty element (<T name="..." />) is read as null. Type names written by Sims4Toolkit (Int8 and UInt8) are accepted along with Sims 4 Studio's.

public XDocument ToXml()

XDocument

Remarks

A null string is written as an empty element (<T name="..." />) and an empty string as an element with empty content (<T name="..."></T>), which FromXml(XDocument) tells apart (Sims 4 Studio reads both as empty strings). An empty vector is written the same way as a null one, which Encode() also writes the same way.

Exceptions

InvalidOperationException

Two different schemas have the same hash or the same name, a name or string contains characters XML cannot represent, or an object or vector contains itself
