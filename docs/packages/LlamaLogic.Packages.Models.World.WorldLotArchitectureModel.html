Remarks

A world file is a package (see DataBasePackedFile); this models one of the resources in it, not the file. The game names the resource after the lot template it belongs to; see GetKey(uint).

Remarks

The game derives the key from a file name: the instance is the FNV-1 64-bit hash of 1- followed by the lot template id in eight lowercase hexadecimal digits, and the type is the FNV-1 32-bit hash of the extension dat. The WorldLotObjects resource of the same lot template has the same instance.
