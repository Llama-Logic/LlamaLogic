Remarks

Tuning refers to a configuration with a key of type AudioConfigurationReference and the configuration's instance. A configuration's Samples are the instances of AudioVocals resources (with their AudioEffects bodies, if streamed), and nearly all of the game's configurations have a Parent. Versions 1 through 7 are supported; version 3 is that of nearly all of the game's configurations. Adapted from S4S by Andrew, extended to read the list version 3 added, which S4S does not.
