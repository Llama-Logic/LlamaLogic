DataBasePackedFile.CopyTo, SaveAs and SaveAsAsync now write the correct index size when some entries lack extended compression fields, so the packages they write from such sources can be reopened.
DataBasePackedFile now reads completely from streams that return fewer bytes than requested per read, both when opening packages and when reading resources, on every target framework.
ZLibDecompress and ZLibDecompressAsync now throw EndOfStreamException when the data decompresses to fewer bytes than requested instead of returning a partly empty result.
Reading the raw content of a resource marked uncompressed now returns the bytes the index says are stored instead of reading as many bytes as its decompressed size, which could run into the following resource.
