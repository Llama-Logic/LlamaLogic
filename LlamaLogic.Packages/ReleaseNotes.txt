Added AnimationStateMachineModel for AnimationStateMachine resources (ASMs, also known as JAZZ), which decodes both the binary packed XML and the XML text Maxis ships them in, along with DataBasePackedFile.GetAnimationStateMachine and its asynchronous counterpart, and Model.Decode, Model.GetModelType, Model.GetName and Model.GetNameAsync now support the type.
DataBasePackedFile.GetDdsAsPng and GetDdsAsPngAsync now return the PNG stored under a key of a type tuning uses to refer to images (such as PNGImage) when the package has no DSTImage resource with the same group and instance, rather than failing to decode it as a DirectDraw Surface.
