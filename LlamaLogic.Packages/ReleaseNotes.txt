DataBasePackedFile now reads and writes DBPF 1.x packages (The Sims 2) in the 1.x format: it reads the 1.x index, decompresses the resources the DIR resource lists as compressed, writes the 1.x header and index, and keeps the DIR resource up to date when writing (removing it when nothing is compressed).
DataBasePackedFile Set and SetAsync methods compress the resources of DBPF 1.x packages only with Maxis' internal algorithm, and throw NotSupportedException for compression modes other than Auto, ForceInternal, and ForceOff.
Setting DataBasePackedFile.FileVersion between 1.x and any other version now throws InvalidOperationException while the package contains compressed or deleted resources, because their stored forms differ between the two.
