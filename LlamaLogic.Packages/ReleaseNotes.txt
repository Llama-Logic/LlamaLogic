ResourceType now gives 19 engine settings tuning types (AutomationTuning, BuildBuyTuning, HsvTweakerSettingsTuning, NativeBuildBuyTuning, NativeSeasonsWeatherTuning, RegionSortTuning, the eight Renderer settings, the two Telemetry settings, ThumbnailTuning, VideoGlobalTuning, and VideoPlaylistTuning) the type IDs the game uses (the FNV-1 hash of the game's case-preserved type name) instead of the hash of the lowercased name, which no real package uses.
ResourceType has 13 new members taken from the game's own resource type table: CASPreferenceGroupTuning, CheatSheetTuning, DynastySeedTuning, GetawayChallengeTuning, GPINI, HalfWallTrim, MTXBundle, ObjDef, SmallBusinessBinaryTuning, SmallBusinessSeedTuning, TuningDependenciesCache, TuningDescription, and UniversityCourseScheduleTuning; the seven tuning types are treated as tuning markup.
