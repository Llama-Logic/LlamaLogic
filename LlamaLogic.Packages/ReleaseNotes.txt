Added AnimationStateMachineModel for AnimationStateMachine resources (ASMs, also known as JAZZ), which decodes both the binary packed XML and the XML text Maxis ships them in, along with DataBasePackedFile.GetAnimationStateMachine and its asynchronous counterpart, and Model.Decode, Model.GetModelType, Model.GetName and Model.GetNameAsync now support the type.
DataBasePackedFile.GetDdsAsPng and GetDdsAsPngAsync now return the PNG stored under a key of a type tuning uses to refer to images (such as PNGImage) when the package has no DSTImage resource with the same group and instance, rather than failing to decode it as a DirectDraw Surface.
Added DirectDrawSurface.GetUnshuffledDdsData, which gets a DirectDraw Surface the way other tools expect it, unshuffling the shuffled surfaces The Sims 4 stores its images as (DSTImage).
Added ElectronicArtsAudioCore.GetMp3, which rebuilds The Sims 4's sounds (AudioVocals headers, with their AudioEffects bodies when streamed) as MP3 without re-encoding them, and ElectronicArtsAudioCoreHeader.Read, which reads their headers; the rebuild is adapted from vgmstream, whose license is in Formats/Vgmstream/license.txt.
Added ElectronicArtsAudioCore.CreateFromMp3, which makes The Sims 4 sounds (AudioVocals, with an AudioEffects body when streamed) from MP3s without re-encoding them, laying them out as the game does, and AudioConfigurationModel for AudioConfiguration resources (PROPX), which decodes and re-encodes every one of the game's configurations byte for byte.
